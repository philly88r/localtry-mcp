# LocalTry MCP directory listing

## Name

LocalTry AI CRM

## Tagline

Run and customize your CRM from any MCP-compatible AI.

## Short description

Connect an AI assistant to one authorized LocalTry business to search and
update CRM records, run workflows, inspect activity, and safely customize that
business's workspace.

## Long description

LocalTry MCP turns an authorized AI assistant into an operating interface for
one LocalTry business. Users can search customers, companies, contacts, leads,
jobs, estimates, invoices, documents, and workflows; create or update validated
records; run saved workflows; inspect recent activity; and operate LocalTry
Command for verified multi-step work.

The remote MCP server is available now for compatible AI clients. A dedicated
LocalTry ChatGPT plugin is coming soon and is currently in OpenAI review.

Owners can also inspect the current workspace architecture, create a versioned
customization plan, approve and apply it, review prior versions, and restore an
earlier version. Every authorization is bound to one verified LocalTry user,
business, role, and permission set. Tools never accept a tenant identifier and
never expose raw SQL, connector credentials, passwords, or session tokens.

## Authentication

OAuth 2.1 with PKCE, dynamic client registration, short-lived access tokens,
and refresh tokens. Users authorize one visible LocalTry workspace.
